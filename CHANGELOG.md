# Changelog

## 1.0.0
First release.
- Hides fake Source / CS2 servers from Steam's built-in server browser (fake player counts, padded player lists, copies, spam farms, odd ports).
- Shows the real player count for servers that only pad their list.
- One uniform server-name style (`flag  Mode | Name`), real country from the IP address.
- Hide or allow whole countries (closest first, with flags).
- Always on, restarts itself when settings change, lives in the tray, optional start with Windows.
- "Open server browser" button.
