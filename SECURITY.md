# Security policy

CS2 Server Browser Fix runs with Administrator rights and loads the WinDivert packet driver, so security reports are welcome.

**Please report vulnerabilities privately** through GitHub: *Security → Report a vulnerability* on this repository. Do not open a public issue for them. You will get a reply as soon as possible.

Only the latest release is supported. The app sends no data anywhere (see "Privacy" in the README), so there is no server side to attack.
